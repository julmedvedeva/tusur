## ЛР1 (вариант 5) — Защита Windows 10

VM Win10, пароль **Qwerty123**.

1. Открыть mmc → добавить оснастку «Локальные пользователи и группы».
2. Создать юзера со своими инициалами.
   📸 скрин: окно создания нового пользователя.
3. Убрать галку «Срок действия пароля неограничен» у созданного юзера (иначе gpedit не применится).
4. gpedit.msc → Конфигурация компьютера → Политики учётных записей → Политика паролей:
   - Макс. срок действия пароля: 90 дней
   - Мин. длина пароля: 10 символов
   - Вести журнал паролей: 5
   - Пароль должен отвечать требованиям сложности: Включено
   📸 скрин: список параметров «Политика паролей» после применения (видно все 4 значения).
5. Политика блокировки учётной записи:
   - Пороговое значение блокировки: 7 ошибок
   - Блокировка учётной записи на: 60 мин
   - Сброс счётчика через: 30 мин
   📸 скрин: список параметров «Политика блокировки учётной записи».
6. Войти под созданным юзером → сменить пароль (проверка сложности сработает).
   📸 скрин: окно смены пароля / сообщение об ошибке если пароль простой.
7. 3 раза ввести неверный пароль → проверить блокировку.
   📸 скрин: сообщение «учётная запись заблокирована».
8. Разблокировать юзера через свойства учётки.
9. Открыть cmd от админа:
   ```
   net user User5 <пароль> /add
   net localgroup Гости User5 /add
   net user User5 /times:Mo-Su,08:00-21:00
   ```
   📸 скрин: вывод каждой команды (успешное выполнение).
10. Проверить: `net user User5` — посмотреть параметры, включая группу и время.
    📸 скрин: вывод `net user User5`.
11. gpedit.msc → Конфигурация пользователя → Административные шаблоны → нужный раздел (установка/удаление программ) → запретить установку и удаление программ.
    📸 скрин: включённая политика.
12. Ответить на 10 контрольных вопросов (текст, без скринов).

## ЛР2 (вариант 5) — Сканер уязвимостей ScanOVAL

Разрешено на своём ПК (не обязательно VM).

1. Скачать ScanOVAL + базу OVAL с bdu.fstec.ru/scanoval.
2. Установить ScanOVAL.
   📸 скрин: окно установки/завершения установки.
3. Загрузить в программу базу OVAL-описаний (кнопка «Загрузить»).
   📸 скрин: главное окно с загруженной базой.
4. Нажать «Выполнить аудит» → дождаться сканирования.
   📸 скрин: процесс сканирования.
5. Посмотреть результаты (список найденных уязвимостей).
   📸 скрин: список обнаруженных уязвимостей.
6. Выгрузить отчёт (кнопка отчёта, открывается в браузере).
   📸 скрин: отчёт с таблицей «Уровень опасности / Найдено / Всего» (первый, «до»).
7. Устранить уязвимости по вариант 5: низкий×3, средний×1, высокий×2, критический×2.
   Для каждой — найти уязвимую программу (её версия видна в описании уязвимости), обновить до новой версии (скачать с официального сайта, установить).
   📸 скрин на каждую устранённую уязвимость: страница загрузки новой версии + процесс установки + подтверждение новой версии (через «О программе» или консоль).
8. Повторно запустить аудит ScanOVAL.
   📸 скрин: новый отчёт «после» — видно, что число найденных уязвимостей снизилось.
9. Ответить на 4 контрольных вопроса.

## ЛР4 — Брутфорс xHydra (без вариантов, задание общее)

VirtualBox — установить самостоятельно. Нужны образы **Kali Linux** и **Win7 Client** (скачать из модуля курса).

1. VirtualBox → Файл → Импорт конфигураций → импортировать обе VM (Kali, Win7).
   📸 скрин: главное окно VirtualBox с двумя добавленными машинами.
2. Настройки VirtualBox → Сеть → добавить новую NAT-сеть.
   📸 скрин: окно добавления сети.
3. В настройках каждой VM (Kali и Win7) → Сеть → Адаптер 1 → тип «Сеть NAT» → выбрать созданную сеть (у обеих должна быть одна и та же).
   📸 скрин: настройки сети Win7 + отдельно настройки сети Kali (2 скрина).
4. Запустить обе VM.
5. В Kali: логин **kali** / пароль **kali**. Открыть терминал, выполнить `ifconfig` — узнать свой IP.
   📸 скрин: вывод `ifconfig`.
6. Выполнить `nmap -v -sn <подсеть>` — найти IP машины Win7.
   📸 скрин: вывод nmap со списком хостов.
7. Открыть xHydra:
   - Target → Single Target: IP Win7-машины, Protocol: smb
     📸 скрин: вкладка Target с заполненным адресом и протоколом.
   - Passwords → Username List (файл user_list.txt на рабочем столе), Password List (словарь на рабочем столе)
     📸 скрин: вкладка Passwords с выбранными файлами.
8. Вкладка Start → нажать Start → дождаться подбора.
   📸 скрин: процесс перебора (видно попытки логин/пароль).
9. Когда пароль найден — сохранить (Save Output), зайти под найденной парой логин/пароль в Windows 7.
   📸 скрин: успешный вход в Win7 под подобранной учёткой (главное требование методички).
10. Ответить на 4 контрольных вопроса.
