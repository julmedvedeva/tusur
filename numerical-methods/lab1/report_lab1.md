## 1 Решение уравнений с одной переменной

### 1.1 Задание

Написать программу отделения корней и их уточнения следующими методами:
а) методом дихотомии; б) методом хорд; в) методом золотого сечения;
г) методом Ньютона; д) методом итераций; е) комбинированным методом.

**Вариант 10:**

$$f(x) = 10\cos(x) - 0{,}1x^2$$

**Входные данные:**
- функция f(x), её первая f'(x) и вторая f''(x) производные;
- интервал поиска [a, b] = [−10; 10];
- точность по аргументу ε₁ = 10⁻⁶ и по функции ε₂ = 10⁻⁶.

**Выходные данные:** корни ξᵢ, значения f(ξᵢ), количество итераций, количество вычислений f, f', f'', время счёта, параметр сходимости α.

---

### 1.2 Теоретический материал

Производные функции:

$$f'(x) = -10\sin(x) - 0{,}2x, \quad f''(x) = -10\cos(x) - 0{,}2.$$

**Отделение корней.** На равномерной сетке с шагом h = 0,5 ищутся соседние точки xᵢ, xᵢ₊₁, для которых f(xᵢ)·f(xᵢ₊₁) ≤ 0 — смена знака указывает на наличие корня в интервале [xᵢ, xᵢ₊₁].

**Метод дихотомии (половинного деления).** На каждом шаге интервал [a, b] делится пополам. Сторона, содержащая корень (где f·f ≤ 0), принимается за новый интервал. Остановка: (b−a)/2 < ε₁. Сходимость линейная, α = 0,5.

**Метод хорд.** Интерполируется хорда между двумя концами отрезка. Новое приближение — пересечение хорды с осью x:

$$x_n = a_n - \frac{f(a_n)}{f(b_n) - f(a_n)}(b_n - a_n).$$

Остановка: |xₙ − xₙ₋₁| < ε₁. Сходимость суперлинейная.

**Метод золотого сечения.** Интервал делится в отношении золотого сечения γ = (√5+1)/2 ≈ 1,618. На каждом шаге длина интервала уменьшается в γ раз. Сходимость линейная, α = γ−1 ≈ 0,618.

**Метод Ньютона (касательных).** Итерационная формула:

$$x_n = x_{n-1} - \frac{f(x_{n-1})}{f'(x_{n-1})}.$$

Начальное приближение x₀ выбирается из условия f(x₀)·f''(x₀) > 0. Сходимость квадратичная, α ≈ порядок 2.

**Метод простых итераций.** Уравнение f(x) = 0 переписывается в виде x = g(x) = x − τ·f(x). Коэффициент τ = 2/(M+m), где M и m — максимум и минимум f'(x) на [a,b]. Условие сходимости: |g'(x)| = |1 − τ·f'(x)| < 1.

**Комбинированный метод.** Один конец обрабатывается по методу Ньютона (квадратичная сходимость), другой — по методу хорд (суперлинейная). Метод Ньютона работает с концом, где f·f'' > 0.

## 2 Решение систем линейных уравнений

### 2.1 Задание

Написать программу решения системы линейных алгебраических уравнений методами: Гаусса, ортогонализации, Халецкого (LU-декомпозиции), простой итерации, Зейделя.

**Вариант 10:**

$$\begin{cases}
7{,}9x_1 + 5{,}6x_2 + 5{,}7x_3 - 7{,}2x_4 = 6{,}68 \\
8{,}5x_1 - 4{,}8x_2 + 0{,}8x_3 + 3{,}5x_4 = 9{,}95 \\
4{,}3x_1 + 4{,}2x_2 - 3{,}2x_3 + 9{,}3x_4 = 8{,}6 \\
3{,}2x_1 - 1{,}4x_2 - 8{,}9x_3 + 3{,}3x_4 = 1{,}0
\end{cases}$$

---

### 2.2 Теоретический материал

**Метод Гаусса** (с частичным выбором ведущего элемента). Прямой ход — приведение матрицы к верхнетреугольному виду. Обратный ход — вычисление переменных. Сложность O(n³).

**Метод ортогонализации (QR).** Матрица A = QR, где Q ортогональна, R верхнетреугольна. Строится по схеме Грама–Шмидта. Решение: Rx = Qᵀb → обратная подстановка.

**Метод Халецкого (LU-декомпозиция).** A = LU, L — нижнетреугольная с единицами на диагонали, U — верхнетреугольная. Последовательно решаются Ly = b и Ux = y.

**Метод простой итерации (Якоби).** Итерационная схема:
$$x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j \ne i} a_{ij} x_j^{(k)}\right).$$
Условие сходимости: спектральный радиус матрицы итерации B < 1 (достаточное: диагональное преобладание).

**Метод Зейделя (Гаусс–Зейдель).** Аналогично методу Якоби, но новые значения x используются немедленно:
$$x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j < i} a_{ij} x_j^{(k+1)} - \sum_{j > i} a_{ij} x_j^{(k)}\right).$$
Сходится быстрее Якоби при тех же условиях.

---

### 2.3 Порядок выполнения работы

1. Для прямых методов (Гаусс, QR, LU) — разложение и подстановка.
2. Для итерационных методов — проверка условия сходимости (спектральный радиус матрицы итерации). При ρ(B) ≥ 1 метод расходится.
3. Если диагональное преобладание отсутствует — применяется преобразование к нормальным уравнениям A^T·A·x = A^T·b.

## 3 Вычисление определителей матриц

### 3.1 Задание

Написать программу вычисления определителя матрицы методами Гаусса и декомпозиции (LU). Использовать матрицу из задания 6.2.1.

---

### 3.2 Теоретический материал

**Метод Гаусса.** Матрица приводится к верхнетреугольному виду; определитель равен произведению элементов главной диагонали с учётом знака, меняющегося при перестановках строк:
$$\det(A) = (-1)^s \prod_{i=1}^n u_{ii},$$
где s — число перестановок строк.

**LU-декомпозиция.** A = LU, det(L) = 1 (единицы на диагонали), поэтому:
$$\det(A) = \det(L) \cdot \det(U) = \prod_{i=1}^n u_{ii}.$$

---

### 3.3 Порядок выполнения работы

1. Гаусс: прямой ход с частичным выбором ведущего элемента, подсчёт числа перестановок, произведение диагоналей.
2. LU: вычисление разложения, произведение диагонали U.

## 4 Вычисление обратной матрицы

---

### 4.2 Теоретический материал

**Метод Гаусса.** Решаем n систем A·xᵢ = eᵢ (i = 1,…,n), где eᵢ — единичные векторы. Столбцы xᵢ образуют A⁻¹.

**Метод ортогонализации (QR).** Из A = QR получаем A⁻¹ = R⁻¹Qᵀ. R⁻¹ вычисляется обратной подстановкой.

**Метод Халецкого (LU).** Для каждого единичного вектора eᵢ последовательно решаются Ly = eᵢ и Ux = y.

Контроль точности: максимальный элемент матрицы невязки |A·A⁻¹ − I|.

---

### 4.3 Порядок выполнения работы

Для каждого из трёх методов: вычислить разложение → для каждого столбца единичной матрицы применить прямую и обратную подстановку → собрать A⁻¹ → вычислить невязку.
