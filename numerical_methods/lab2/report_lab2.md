## 1 Приближение функций — интерполяция

### 1.1 Задание

Написать программу интерполяции таблично заданной функции с помощью полиномов Ньютона и Лагранжа.

**Вариант 10:**

$$y = \sin^2 x + 1, \quad x \in \left[0,\, \frac{\pi}{2}\right], \quad h = \frac{\pi}{20}.$$

- Исходная сетка: $x_i = i \cdot h$, $i = 0, 1, \ldots, 10$ (11 узлов).
- Новая сетка: $x_j = j \cdot \dfrac{h}{2}$, $j = 0, 1, \ldots, 20$ (21 точка).

**Выходные данные:** новая сетка, значения полинома, погрешность |y_точн − y_полином|.

***

### 1.2 Теоретический материал

**Полином Ньютона (вперёд, равномерная сетка).**

Для равномерной сетки с шагом h вводятся конечные разности:
$$\Delta^k y_i = \Delta^{k-1} y_{i+1} - \Delta^{k-1} y_i, \quad \Delta^0 y_i = y_i.$$

Полином Ньютона вперёд:
$$P_n(x) = y_0 + \frac{t}{1!}\Delta y_0 + \frac{t(t-1)}{2!}\Delta^2 y_0 + \ldots + \frac{t(t-1)\cdots(t-n+1)}{n!}\Delta^n y_0,$$

где $t = (x - x_{\text{idx}})/h$ — нормированный аргумент от ближайшего левого узла.

**Полином Лагранжа.**

$$P_n(x) = \sum_{i=0}^{n} y_i \cdot L_i(x), \quad L_i(x) = \prod_{\substack{j=0 \\ j \ne i}}^{n} \frac{x - x_j}{x_i - x_j}.$$

Погрешность интерполяции полиномом n-го порядка:
$$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!} \prod_{i=0}^{n}(x - x_i).$$

***

### 1.3 Порядок выполнения работы

1. Построить таблицу конечных разностей Δᵏyᵢ.
2. Для каждой точки новой сетки xⱼ:
   - **Ньютон**: найти ближайший левый узел idx (с запасом от правой границы), вычислить t, просуммировать члены формулы.
   - **Лагранж**: для каждого i вычислить Lᵢ(xⱼ) и просуммировать yᵢ·Lᵢ(xⱼ).
3. Вычислить погрешность |y(xⱼ) − Pₙ(xⱼ)|.

## 2 Численное дифференцирование

### 2.1 Задание

Написать программу вычисления первой и второй производной табличной функции с помощью полиномов Ньютона и Лагранжа. Использовать функцию и сетки из задания 6.3.

### 2.2 Теоретический материал

Точные производные функции y = sin²x + 1:
$$y'(x) = \sin(2x), \quad y''(x) = 2\cos(2x).$$

**Производная полинома Ньютона (вперёд).**

Дифференцируя полином Ньютона по t = (x−x_idx)/h:

$$P'(x) = \frac{1}{h}\left[\Delta y_0 + \frac{2t-1}{2}\Delta^2 y_0 + \frac{3t^2 - 6t + 2}{6}\Delta^3 y_0 + \frac{4t^3-18t^2+22t-6}{24}\Delta^4 y_0 + \ldots\right]$$

$$P''(x) = \frac{1}{h^2}\left[\Delta^2 y_0 + (t-1)\Delta^3 y_0 + \frac{6t^2-18t+11}{6}\Delta^4 y_0 + \ldots\right]$$

**Производная полинома Лагранжа.**

$$P'(x) = \sum_{i=0}^n y_i \cdot L_i'(x), \quad L_i'(x) = \sum_{\substack{k=0\\k\ne i}}^n \frac{1}{x_i - x_k} \prod_{\substack{j=0\\j\ne i, j\ne k}}^n \frac{x-x_j}{x_i-x_j}.$$

## 3 Численное интегрирование

### 3.1 Задание

1. Написать программу вычисления интеграла по формулам трапеций, Симпсона и прямоугольников с автоматическим выбором шага интегрирования.
2. Написать программу вычисления интеграла по формуле Гаусса.

**Вариант 10:**

$$I = \int_0^2 e^{-x^2} \cos x \, dx, \quad n = 6 \text{ (порядок формулы Гаусса)}.$$

***

### 3.2 Теоретический материал

**Формула трапеций:**
$$I \approx h\left[\frac{f(a)+f(b)}{2} + \sum_{i=1}^{n-1} f(x_i)\right], \quad h = \frac{b-a}{n}.$$
Погрешность: $O(h^2)$, порядок p = 2.

**Формула Симпсона:**
$$I \approx \frac{h}{3}\left[f(a) + 4f(x_1) + 2f(x_2) + 4f(x_3) + \ldots + 4f(x_{n-1}) + f(b)\right].$$
Погрешность: $O(h^4)$, порядок p = 4. Требует чётного n.

**Формула средних прямоугольников:**
$$I \approx h \sum_{i=0}^{n-1} f\!\left(a + \left(i+\tfrac{1}{2}\right)h\right).$$
Погрешность: $O(h^2)$, порядок p = 2.

**Правило Рунге** (автовыбор шага). Шаг удваивается (n → 2n) до выполнения:
$$\frac{|I_{2n} - I_n|}{2^p - 1} < \varepsilon \cdot |I_{2n}|.$$

**Формула Гаусса–Лежандра.** Интеграл на [a, b] через узлы и веса на [−1, 1]:
$$I \approx \frac{b-a}{2} \sum_{k=1}^n w_k \, f\!\left(\frac{a+b}{2} + \frac{b-a}{2} t_k\right).$$
Для n = 6: точность для полиномов степени ≤ 11.

### 3.3 Порядок выполнения работы

**Квадратурные формулы с правилом Рунге:**
1. Задать начальное число интервалов n₀ = 4.
2. Вычислить I_n, затем I_{2n}.
3. Проверить критерий Рунге; при выполнении — результат I_{2n}, иначе n ← 2n и повторить.

2. Преобразовать к отрезку [0, 2].
3. Вычислить взвешенную сумму.
