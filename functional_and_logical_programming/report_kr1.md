## Краткое теоретическое введение

**Функциональное программирование** — парадигма, в которой программа строится
из вызовов функций, а не из последовательности операторов присваивания. В чистом
функциональном языке нет цикла и оператора присваивания; повторяющиеся вычисления
выражаются через **рекурсию** — функцию, вызывающую саму себя для более простой
подзадачи.

**Синтаксис Лиспа.** Программа записывается в виде списков в скобках; первый
элемент списка — имя функции, остальные — её аргументы (префиксная запись).
Например, `(+ 2 3)` вычисляет 5. Символ `'` (кавычка) запрещает вычисление
и позволяет задать список как данные: `'(a b c)`.

**Логические значения.** Истина обозначается `t`, ложь и пустой список — `nil`.
Встроенные `and` и `or` возвращают не только `t`/`nil`, но и содержательное
значение: `and` — значение последнего аргумента, если все истинны; `or` —
первый истинный аргумент.

**Условное выражение** `(if условие тогда иначе)` вычисляет вторую ветвь, если
условие истинно, иначе — третью.

**Рекурсия** требует двух частей: базового случая (где рекурсия
останавливается) и рекурсивного шага (сведение задачи к более простой
с вызовом самой функции). Результат собирается из значений, возвращаемых
рекурсивными вызовами.

## Порядок выполнения работы

### Задача 1. Функции `and4` и `or4`

**Условие.** Написать с помощью композиции условных выражений функции четырёх
аргументов `(and4 x1 x2 x3 x4)` и `(or4 x1 x2 x3 x4)`, совпадающие со
встроенными функциями `and` и `or` от четырёх аргументов.

Логическое «И» для двух аргументов выражается через `if`:
`(and a b)` ≡ `(if a b nil)` — если `a` ложно, результат `nil`; иначе результат
равен `b`. Для четырёх аргументов условные выражения вкладываются друг в друга:
при истинности очередного аргумента проверка продолжается, при ложности —
возвращается `nil`. В самой глубокой ветви возвращается последний аргумент `x4`,
чтобы поведение совпало со встроенным `and`.

Функция `or4` строится зеркально: при истинности очередного аргумента он сразу
возвращается (как значение), иначе проверка продолжается; если все ложны —
результат `nil`.

### Задача 2. Последний элемент списка

**Условие.** Написать функцию, вычисляющую последний элемент списка.

Применяется простая рекурсия по списку:

- базовый случай: если хвост списка пуст (`(null (rest lst))`), то текущий
  первый элемент и есть последний;
- рекурсивный шаг: иначе последний элемент списка равен последнему элементу
  его хвоста — вызов той же функции для `(rest lst)`.

Имя `last` занято встроенной функцией, поэтому функция названа `last-elem`.

### Задача 3. Повтор элемента n раз

**Условие.** Написать функцию от двух аргументов `x` и `n`, создающую список из
`n` повторений элемента `x`.

Применяется рекурсия по счётчику `n`:

- базовый случай: при `n = 0` возвращается пустой список `nil`;
- рекурсивный шаг: список из `n` копий равен `(cons x ...)` — один элемент `x`,
  приклеенный к списку из `n − 1` копий, полученному рекурсивным вызовом.

## Результаты работы программы

Все функции загружены в SBCL и проверены на контрольных примерах. Результаты
приведены в Таблице 1.1.

**Таблица 1.1 — Результаты тестирования функций**

| Вызов | Ожидаемый результат | Полученный результат |
|-------|--------------------|--------------------|
| `(and4 t t t t)` | T | T |
| `(and4 t t nil t)` | NIL | NIL |
| `(and4 1 2 3 4)` | 4 | 4 |
| `(or4 nil nil nil nil)` | NIL | NIL |
| `(or4 nil nil 5 nil)` | 5 | 5 |
| `(or4 t nil nil nil)` | T | T |
| `(last-elem '(a b c))` | C | C |
| `(last-elem '(1 2 3 4 5))` | 5 | 5 |
| `(last-elem '(x))` | X | X |
| `(repeat 'a 3)` | (A A A) | (A A A) |
| `(repeat 5 4)` | (5 5 5 5) | (5 5 5 5) |
| `(repeat 'x 0)` | NIL | NIL |

Полученные результаты совпадают с ожидаемыми во всех случаях. Функции `and4`
и `or4` возвращают те же значения, что и встроенные `and`/`or`, включая
содержательное значение (не только `t`/`nil`).
