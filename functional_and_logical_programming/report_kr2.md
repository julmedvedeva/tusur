## Краткое теоретическое введение

**Вспомогательные функции.** Сложную задачу удобно разбивать на подзадачи,
каждая из которых решается отдельной функцией. Вспомогательная функция может
быть определена как самостоятельная (`defun`) или как локальная — внутри
основной функции (форма `labels`). В данной работе вспомогательные функции
`ispr` (для проверки простоты) и `insert` (для сортировки) оформлены отдельными
определениями.

**Рекуррентное определение простого числа.** Число `n` простое, если оно не
делится ни на одно число от 2 до `n − 1`. Это выражается через более общий
предикат `(ispr n m)` — «`n` не делится ни на одно число в диапазоне
[`m`, `n − 1`]»: `(ispr n m)` истинно, если `n = m`, либо если истинно
`(ispr n (m+1))` и `n` не делится на `m`. Проверка простоты: `(ispr n 2)`.

**Сортировка простой вставкой.** Список сортируется поэлементно: каждый
очередной элемент вставляется на своё место в уже отсортированную часть списка,
так что упорядоченность сохраняется.

**Функционалы.** Функционал — функция, принимающая другую функцию как аргумент.
Переданная функция вызывается через `funcall`, а сама функция передаётся с
помощью синтаксиса `#'имя` (получение функционального значения по имени). Это
позволяет писать обобщённые функции, поведение которых задаётся передаваемым
предикатом.

## Порядок выполнения работы

### Задача 1. Проверка числа на простоту

**Условие.** Написать функцию, определяющую, является ли данное натуральное
число простым. Воспользоваться более общей задачей: `(ispr n m)` — «Число `n`
не делится ни на одно число большее или равное `m` и меньшее `n`». Имеем:
`(ispr n m)` истинно, во-первых, если `n = m`, и, во-вторых, если истинно
`(ispr n (m+1))` и `n` не делится на `m`.

Вспомогательный предикат `ispr` реализован рекурсией по `m` (от 2 вверх к `n`):

- базовый случай `(= n m)` — диапазон исчерпан, делителей не найдено, результат `t`;
- рекурсивный шаг — `(and (ispr n (1+ m)) (not (zerop (mod n m))))`: `n` не
  делится ни на что дальше и не делится на текущее `m`.

Делимость проверяется как `(zerop (mod n m))` — равенство нулю остатка от
деления. Основная функция `prime` вызывает `(ispr n 2)`.

### Задача 2. Сортировка простой вставкой

**Условие.** Написать функцию, сортирующую список чисел алгоритмом простой
вставки.

Задача решена с помощью вспомогательной функции `insert`, вставляющей один
элемент `x` в уже отсортированный список `lst` с сохранением порядка:

- если список пуст — результат `(list x)`;
- если `x ≤ (first lst)` — место найдено, `x` ставится в начало: `(cons x lst)`;
- иначе — первый элемент сохраняется, а `x` вставляется в хвост рекурсивно.

Основная функция `sort-ins` рекурсивно сортирует хвост списка, после чего
вставляет голову в отсортированный хвост функцией `insert`.

### Задача 3. Предикат `all`

**Условие.** Написать функцию `(all p x)`, проверяющую «Для всех ли элементов
списка `x` выполняется предикат `p`?» (`p` — функция или функциональное имя).

Функция реализована как функционал: предикат `p` применяется к каждому элементу
через `funcall`. Рекурсия по списку:

- базовый случай — пустой список, результат `t` (для пустого списка условие
  считается выполненным);
- если `(funcall p (first x))` истинно — проверяется хвост списка;
- иначе (найден элемент, не удовлетворяющий `p`) — результат `nil`.

При вызове предикат передаётся синтаксисом `#'имя`, например `#'numberp`,
`#'evenp`, `#'plusp`.
