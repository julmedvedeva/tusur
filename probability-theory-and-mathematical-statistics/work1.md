## Задача 1 — Нормальное распределение

**Условие:** Еженедельный выпуск продукции на заводе распределён по нормальному закону: μ = 134786 ед., σ = 13000 ед. Найти вероятность того, что еженедельный выпуск окажется ниже 100000 ед.

**Решение:**

1. Вычислим z-оценку:
```
z = (x − μ) / σ = (100000 − 134786) / 13000 = −2.68
```

2. По таблице функции Лапласа: Φ₀(2.68) = 0.4963

3. Так как z < 0:
```
P(X < 100000) = 0.5 − Φ₀(|z|) = 0.5 − 0.4963 = 0.0037
```

**Ответ:** P ≈ 0.0037 (0.37%) — вероятность очень мала.

## Задача 2 — Интервальные оценки

**Условие:** Из 50 счетов по 20 имело место движение денежных средств. Построить 95%-й доверительный интервал для доли счетов в генеральной совокупности.

**Решение:**

1. Выборочная доля:
```
w = m/n = 20/50 = 0.4
```

2. Для 95% доверительного интервала: z = 1.96

3. Погрешность:
```
Δ = z · √(w·(1−w) / n) = 1.96 · √(0.4 · 0.6 / 50) = 1.96 · √0.0048 = 1.96 · 0.069 = 0.135
```

4. Доверительный интервал:
```
(w − Δ; w + Δ) = (0.4 − 0.135; 0.4 + 0.135) = (0.265; 0.535)
```

**Ответ:** С вероятностью 95% доля счетов с движением средств в генеральной совокупности находится в интервале **(0.265; 0.535)**.

## Задача 3 — Проверка статистических гипотез

**Условие:** Доля госпредприятий в области p₀ = 2.3%. Среди n = 2236 машиностроительных предприятий доля p̂ = 2.1%. При α = 0.05 проверить, существенно ли меньше доля в машиностроении.

**Решение:**

H₀: p = p₀ = 0.023  
H₁: p < p₀ (односторонний левый тест)

1. z-статистика:
```
z = (p̂ − p₀) / √(p₀·(1−p₀) / n)
  = (0.021 − 0.023) / √(0.023 · 0.977 / 2236)
  = −0.002 / √0.000010
  = −0.002 / 0.003
  = −0.667
```

2. Критическое значение для одностороннего теста α = 0.05: z_кр = −1.645

3. Сравнение:
```
z_набл = −0.667 > z_кр = −1.645 → H₀ не отвергается
```

**Ответ:** Разница несущественна. Нельзя утверждать, что доля госпредприятий в машиностроении значимо меньше, чем в целом по области.

## Задача 4 — Критерий согласия Пирсона

**Условие:** Проверить нормальность распределения X при α = 0.05.

| Интервал | [0; 0.3) | [0.3; 0.6) | [0.6; 0.9) | [0.9; 1.2) | [1.2; 1.5) | [1.5; 1.8) |
|----------|----------|------------|------------|------------|------------|------------|
| nⱼ       | 3        | 4          | 7          | 9          | 5          | 3          |

n = 31

**Решение:**

**1. Среднее x̄:**

| Интервал | Середина xⱼ | nⱼ | xⱼ·nⱼ |
|----------|------------|-----|-------|
| [0; 0.3) | 0.15 | 3 | 0.45 |
| [0.3; 0.6) | 0.45 | 4 | 1.80 |
| [0.6; 0.9) | 0.75 | 7 | 5.25 |
| [0.9; 1.2) | 1.05 | 9 | 9.45 |
| [1.2; 1.5) | 1.35 | 5 | 6.75 |
| [1.5; 1.8) | 1.65 | 3 | 4.95 |
| **Σ** | | **31** | **28.65** |

```
x̄ = 28.65 / 31 = 0.924
```

**2. Стандартное отклонение s:**

| xⱼ | xⱼ² | nⱼ | xⱼ²·nⱼ |
|----|-----|----|--------|
| 0.15 | 0.0225 | 3 | 0.0675 |
| 0.45 | 0.2025 | 4 | 0.81 |
| 0.75 | 0.5625 | 7 | 3.9375 |

| 1.35 | 1.8225 | 5 | 9.1125 |
| 1.65 | 2.7225 | 3 | 8.1675 |
| **Σ** | | | **32.015** |

```
s = √(32.015/31 − 0.924²) = √(1.0327 − 0.8538) = √0.1789 = 0.42
```

**3. z-границы интервалов:**

| Граница | z | Φ₀(\|z\|) | Φ(z) |
|---------|---|--------|------|
| 0.0 | −2.20 | 0.4861 | 0.0139 |
| 0.3 | −1.49 | 0.4319 | 0.0681 |
| 0.6 | −0.77 | 0.2794 | 0.2206 |
| 0.9 | −0.06 | 0.0239 | 0.4761 |
| 1.2 | +0.66 | 0.2454 | 0.7454 |
| 1.5 | +1.37 | 0.4147 | 0.9147 |
| 1.8 | +2.09 | 0.4821 | 0.9821 |

**4. Объединение интервалов** (n_теор < 5 → объединяем):

| Интервал | n_набл | p | n_теор |
|----------|--------|---|--------|
| [0; 0.6) | 7 | 0.0681−0.0139+0.0139 = 0.0681 | 2.11 |

**6. χ²_кр** (df = 1, α = 0.05) = **3.8**

```
χ²_набл = 13.383 > χ²_кр = 3.8 → H₀ отвергается
```

## Задача 5 — Ранговая корреляция

**Условие:** Найти коэффициент ранговой корреляции Спирмена и проверить его значимость при α = 0.05.

| Ранг X | 9 | 6 | 8 | 10 | 5 | 7 | 4 | 2 | 3 | 1 |
|--------|---|---|---|----|---|---|---|---|---|---|
| Ранг Y | 8 | 7 | 9 | 10 | 5 | 6 | 4 | 3 | 2 | 1 |

**Решение:**

**1. Таблица разностей:**

| i | Ранг X | Ранг Y | dᵢ | dᵢ² |
|---|--------|--------|-----|-----|
| 1 | 9 | 8 | 1 | 1 |
| 2 | 6 | 7 | −1 | 1 |
| 3 | 8 | 9 | −1 | 1 |
| 4 | 10 | 10 | 0 | 0 |
| 5 | 5 | 5 | 0 | 0 |
| 6 | 7 | 6 | 1 | 1 |
| 7 | 4 | 4 | 0 | 0 |
| 8 | 2 | 3 | −1 | 1 |
| 9 | 3 | 2 | 1 | 1 |
| 10 | 1 | 1 | 0 | 0 |
| **Σ** | | | | **6** |

**2. Коэффициент Спирмена:**
```
r = 1 − 6·Σdᵢ² / (n·(n²−1)) = 1 − 6·6 / (10·99) = 1 − 36/990 = 0.96
```

**3. Проверка значимости:**
```
t = r · √(n−2) / √(1−r²) = 0.96 · √8 / √(1−0.9216) = 0.96 · 2.82 / 0.28 = 9.67
```

t_кр (df = 8, α = 0.05) = 2.31

```
t_набл = 9.67 > t_кр = 2.31 → корреляция значима
```

**Ответ:** r = 0.96 — сильная положительная ранговая корреляция между длиной головы и длиной грудного плавника окуня. Корреляция значима при α = 0.05.

## Задача 6 — Линейная корреляция и регрессия

**Условие:** Исследовать зависимость времени закрепления детали (Y, с) от веса детали (X, кг).

| X | 2.2 | 2.3 | 2.4 | 2.5 | 2.6 | 2.7 | 2.8 | 3.0 | 3.1 | 3.2 |
|---|-----|-----|-----|-----|-----|-----|-----|-----|-----|-----|
| Y | 7   | 8   | 10  | 12  | 13  | 14  | 15  | 17  | 18  | 20  |

**Решение:**

**1. Диаграмма рассеяния:** точки образуют линейное облако — с ростом X растёт Y. Зависимость линейная, положительная.

**2. Вычисление сумм:**

| X | Y | X² | Y² | X·Y |
|---|---|----|----|-----|
| 2.2 | 7 | 4.84 | 49 | 15.4 |
| 2.3 | 8 | 5.29 | 64 | 18.4 |
| 2.4 | 10 | 5.76 | 100 | 24.0 |
| 2.5 | 12 | 6.25 | 144 | 30.0 |
| 2.6 | 13 | 6.76 | 169 | 33.8 |
| 2.7 | 14 | 7.29 | 196 | 37.8 |
| 2.8 | 15 | 7.84 | 225 | 42.0 |
| 3.0 | 17 | 9.00 | 289 | 51.0 |
| 3.1 | 18 | 9.61 | 324 | 55.8 |
| 3.2 | 20 | 10.24 | 400 | 64.0 |
| **Σ** | **134** | **72.88** | **1960** | **372.2** |

```
x̄ = 26.8/10 = 2.68,   ȳ = 134/10 = 13.4
```

**3. Коэффициент корреляции Пирсона:**
```
r = (ΣXY − n·x̄·ȳ) / √((ΣX² − n·x̄²)·(ΣY² − n·ȳ²))
  = (372.2 − 10·2.68·13.4) / √((72.88 − 10·2.68²)·(1960 − 10·13.4²))
  = 13.08 / √(1.06 · 164.4)
  = 13.08 / 13.2
  = 0.99
```

**4. Проверка значимости:**
```
t = 0.99 · √8 / √(1−0.9801) = 0.99 · 2.82 / 0.14 = 20.01
```

t_кр (df = 8, α = 0.05) = 2.31

```
t_набл = 20.01 > t_кр = 2.31 → корреляция значима
```

**5. Уравнение регрессии:**
```
b = (ΣXY − n·x̄·ȳ) / (ΣX² − n·x̄²) = 13.08 / 1.06 = 12.34
a = ȳ − b·x̄ = 13.4 − 12.34·2.68 = −19.67
```

```
Ŷ = −19.67 + 12.34·X
```

**6. Интерпретация:**
- r = 0.99 — очень сильная положительная линейная зависимость
- При увеличении веса детали на 1 кг время закрепления увеличивается на **12.34 секунды**
- Коэффициент a = −19.67 физического смысла не имеет (вес не может быть 0)

**Ответ:** Между весом детали и временем закрепления существует сильная линейная зависимость. Уравнение регрессии: Ŷ = −19.67 + 12.34·X.
